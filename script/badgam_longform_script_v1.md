# "पचास गज" : Major Somnath Sharma, Badgam 1947
## Long-form Hindi script v1 (target 12:00, about 1,500 words)

Voice: Sarvam Bulbul v3, speaker **anand**. One request per numbered line.

**How to read this sheet**
- **Pace**: the Bulbul `pace` value for that line. 1.0 is normal; 0.85 is slow and heavy; 1.1 is urgent.
- **Pause**: silence added in the edit *after* the line, in seconds. It is never typed into the text.
- **Tag**:
  - **V**: verified across sources.
  - **A**: attributed. The narration itself says "कहा जाता है" or "रिकॉर्ड के मुताबिक़".
  - **D**: disputed. The script names the range.
  - **CHECK**: confirm before the voice render.
- **Numbers**: all are spelled out in words, so the TTS reads them in Hindi.
- **Dialogue**: none is invented. The only quoted words are his last radio message, introduced as a recorded account.
